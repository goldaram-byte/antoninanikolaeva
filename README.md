# CRM «Школа каратэ Николаевой Антонины»

CRM и клиентское приложение школы каратэ по образцу CRM «Поколение».
Фирменные цвета: красный / чёрный / белый.

## Структура

- `server/` — бэкенд: Node.js (ES-модули) + Express + PostgreSQL (чистый SQL через `pg`, без ORM).
- `web/` — фронтенд: React + Vite + Tailwind. Один проект, два приложения:
  - `/admin` — админка для сотрудников (роли и права по галочкам);
  - `/cabinet` — личный кабинет ученика (ставится как PWA).
- `deploy/` — файлы для сервера: служба systemd и конфиг nginx.
- `УСТАНОВКА_НА_СЕРВЕР.md` — пошаговая инструкция развёртывания (Windows + WinSCP).

PWA-манифесты раздельные с первого дня: `manifest.webmanifest` (кабинет,
start_url `/cabinet`) и `admin.webmanifest` (админка, start_url `/admin`),
переключение скриптом в `web/index.html` по текущему пути.

## Запуск локально

```bash
# База: PostgreSQL. Проще всего docker:
cd server && docker compose up -d

cd server
cp .env.example .env        # при docker-варианте менять ничего не нужно
npm install
npm run migrate             # применяет src/schema.sql
npm run seed                # роли, настройки, владелец admin@karate.ru / admin123
npm run dev                 # API на :4000

cd ../web
npm install
npm run dev                 # Vite на :5173
```

Админка: http://localhost:5173/admin (вход `admin@karate.ru` / `admin123`).
Кабинет: http://localhost:5173/cabinet — регистрация доступна только по телефону,
который уже есть в базе клиентов.

## Этапы разработки

1. ✅ Каркас: сервер, схема БД, авторизация (сотрудник/клиент), PWA-скелет, деплой.
2. Клиенты, тарифы, выдача абонементов (со «своей ценой»), оплаты и должники.
3. Расписание, посещаемость (ручная), запись.
4. Кабинет клиента: главная, абонементы, QR, профиль.
5. Уведомления (web-push + Telegram), лояльность, рефералка, рейтинг.
6. Воронка, задачи, зарплата, СКУД-endpoint, контент-раздел.
7. Автобэкапы, финальная инструкция владельцу.

## Примечания

- Иконки в `web/public/` — временные (буква «К» в фирменных цветах). Замените
  на настоящий логотип школы: `logo.png`, `icon-192.png`, `icon-512.png`,
  `apple-touch-icon.png`.
- Параметры центра: направление — каратэ; тренажёрного зала нет; онлайн-оплата
  ЮKassa (ключи подключаются в `.env`); Telegram-бот для уведомлений сотрудникам.
