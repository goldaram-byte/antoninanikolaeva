# Расписание на сайте школы (Tilda и другие конструкторы)

Расписание с сайта берётся прямо из CRM: поменяли занятие в разделе
«Расписание» — на сайте оно обновилось само, ничего перезаливать не нужно.

## Шаг 1. Проверьте, что расписание открыто для сайта

CRM → **Настройки → Расписание на сайте**. Галочка «Показывать расписание на
сайте» должна стоять (по умолчанию стоит). Там же есть прямая ссылка на
страницу расписания — откройте её и убедитесь, что занятия видны:

```
https://karate-nikolaeva.online/raspisanie.html
```

## Шаг 2. Скопируйте код

В том же разделе настроек есть поле «Код для блока „HTML" на Tilda» и
кнопка **скопировать**. Код выглядит так:

```html
<iframe src="https://karate-nikolaeva.online/raspisanie.html"
        style="width:100%;border:0;min-height:600px" id="karateSchedule" loading="lazy"></iframe>
<script>
window.addEventListener("message", function (e) {
  if (e.data && e.data.type === "karate-schedule-height")
    document.getElementById("karateSchedule").style.height = e.data.height + "px";
});
</script>
```

Вторая часть (script) нужна, чтобы блок сам подстраивал высоту под
количество занятий и не оставлял пустого места.

## Шаг 3. Вставьте на Tilda

1. Откройте нужную страницу сайта в Tilda → **«Добавить блок»**.
2. Раздел **«Другое» → блок T123 «HTML-код»** (можно найти поиском по слову
   «HTML»).
3. Нажмите **«Контент»** и вставьте скопированный код в поле.
4. **«Сохранить и закрыть»** → **«Опубликовать»** страницу.

Готово: на странице появится расписание с переключателем филиалов.
На телефоне оно автоматически перестраивается в один столбец.

## Настройки внешнего вида

К адресу в `src` можно дописать параметры (через `?`, несколько — через `&`):

| Параметр | Что делает |
|---|---|
| `?branch=ID` | показать только один филиал, без переключателя |
| `?theme=dark` | тёмная тема (для тёмного сайта) |
| `?accent=%23dc2626` | свой акцентный цвет (символ `#` пишется как `%23`) |
| `?trainer=0` | не показывать имена тренеров |

ID филиала виден в адресной строке CRM или его можно взять из ссылки
`https://karate-nikolaeva.online/api/public/schedule` — там перечислены
филиалы с их ID.

Пример для одного филиала на тёмном сайте:

```
https://karate-nikolaeva.online/raspisanie.html?branch=ВАШ-ID&theme=dark
```

## Частые вопросы

**Расписание не появилось.** Проверьте, что страница
`https://karate-nikolaeva.online/raspisanie.html` открывается сама по себе.
Если пишет «Расписание временно недоступно» — включите галочку в
Настройки → Расписание на сайте.

**Видно старое расписание.** Страница кэшируется на 5 минут — подождите и
обновите страницу сайта с Ctrl+F5.

**Что видят посетители сайта.** Только день, время, название занятия,
филиал, зал и имя тренера. Никаких данных об учениках, оплатах и
посещаемости туда не попадает — их отдаёт только закрытая часть CRM с
входом по паролю.
