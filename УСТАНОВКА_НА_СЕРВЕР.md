# Установка CRM «Школа каратэ Николаевой Антонины» на сервер

Инструкция рассчитана на Windows + WinSCP + консоль сервера (кнопка «Открыть терминал»
в WinSCP или PuTTY). Сервер — VPS с Ubuntu 24.04 (подойдёт Timeweb, reg.ru и т.п.,
самый недорогой тариф с 1–2 ГБ памяти).

> **Важно (урок из опыта):** сразу после заказа VPS зайдите в панель хостинга и
> включите **автосписание оплаты** (или уведомления о низком балансе) и
> **автобэкапы VPS**, если они есть в тарифе. Потеря сервера из-за неоплаты —
> реальный случай, данные тогда спасли чудом.

## Что понадобится

- Доступ к серверу: IP-адрес, логин `root`, пароль (пришлёт хостинг).
- Программа WinSCP (https://winscp.net) — для загрузки файлов.
- Папка проекта на вашем компьютере (эта папка с `server/`, `web/`, `deploy/`).
- Домен (можно добавить позже — без домена всё будет работать по IP, но без SSL).

---

## Шаг 1. Подключиться к серверу

1. Откройте WinSCP → «Новое подключение».
2. Протокол: **SFTP**, адрес: IP сервера, порт 22, логин `root`, пароль из письма хостинга.
3. Нажмите «Войти». Слева — ваш компьютер, справа — сервер.
4. Откройте терминал сервера: в WinSCP меню «Команды → Открыть в PuTTY» (или кнопка терминала).

## Шаг 2. Установить программы на сервер

Вставьте в терминал по одной команде (правой кнопкой мыши = вставить):

```bash
apt update && apt -y upgrade
```

```bash
apt -y install curl git nginx postgresql postgresql-contrib
```

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt -y install nodejs
```

Проверка: `node -v` должно показать v22.x, `psql --version` — PostgreSQL 16.

## Шаг 3. Создать базу данных

```bash
sudo -u postgres psql -c "CREATE USER karate WITH PASSWORD 'ПРИДУМАЙТЕ_ПАРОЛЬ';"
sudo -u postgres psql -c "CREATE DATABASE karate OWNER karate;"
```

Запишите пароль — он понадобится в файле `.env` на шаге 5.

## Шаг 4. Загрузить проект на сервер

1. В терминале создайте папку: `mkdir -p /opt/karate`
2. В WinSCP справа перейдите в `/opt/karate`.
3. Слева найдите папку проекта и перетащите на сервер папки **server** и **web**
   (папки `node_modules` и `dist`, если есть, можно не копировать — соберём на сервере).

## Шаг 5. Настроить бэкенд

```bash
cd /opt/karate/server
cp .env.example .env
nano .env
```

В открывшемся редакторе заполните:

- `DATABASE_URL=postgres://karate:ПАРОЛЬ_ИЗ_ШАГА_3@localhost:5432/karate`
- `JWT_SECRET=` — длинная случайная строка. Сгенерировать прямо в терминале:
  `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` —
  скопируйте результат.
- `CLIENT_ORIGIN=https://ВАШ-ДОМЕН.ru` (пока домена нет — `http://IP-СЕРВЕРА`)
- `CLIENT_DIST=/opt/karate/web/dist`
- `SEED_ADMIN_EMAIL` и `SEED_ADMIN_PASSWORD` — логин и пароль владельца для входа в админку.

Сохранить: `Ctrl+O`, Enter, выйти: `Ctrl+X`.

Установить зависимости, применить схему БД и создать владельца:

```bash
cd /opt/karate/server
npm install
npm run migrate
npm run seed
```

Должно напечатать `✓ Схема применена` и `✓ Сид завершён`.

## Шаг 6. Собрать фронтенд

```bash
cd /opt/karate/web
npm install
npm run build
```

Появится папка `/opt/karate/web/dist` — её и будет раздавать nginx.

## Шаг 7. Запустить бэкенд как службу

```bash
cp /opt/karate/server/../deploy/karate-crm.service /etc/systemd/system/ 2>/dev/null \
  || echo "скопируйте deploy/karate-crm.service через WinSCP в /etc/systemd/system/"
chown -R www-data:www-data /opt/karate
systemctl daemon-reload
systemctl enable --now karate-crm
systemctl status karate-crm
```

Если папку `deploy` на сервер не копировали — перетащите файл
`deploy/karate-crm.service` через WinSCP в `/etc/systemd/system/` и повторите
последние три команды. Статус должен быть зелёный `active (running)`.

Проверка: `curl http://localhost:4000/health` → `{"ok":true,...}`.

## Шаг 8. Настроить nginx

1. Через WinSCP скопируйте `deploy/nginx.conf.example` на сервер в
   `/etc/nginx/sites-available/karate-crm`.
2. Откройте его (двойной щелчок в WinSCP) и замените `ВАШ-ДОМЕН.ru` на ваш домен
   (или на IP сервера, если домена пока нет).
3. В терминале:

```bash
ln -sf /etc/nginx/sites-available/karate-crm /etc/nginx/sites-enabled/karate-crm
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

Откройте в браузере `http://ВАШ-ДОМЕН.ru/admin` (или `http://IP/admin`) —
должна появиться страница входа. Войдите с email и паролем из шага 5.

## Шаг 9. Подключить домен и SSL (когда домен появится)

1. У регистратора домена создайте A-запись: `@` → IP сервера (и `www` → IP сервера).
2. Подождите 10–60 минут, пока запись разойдётся.
3. На сервере:

```bash
apt -y install certbot python3-certbot-nginx
certbot --nginx -d ВАШ-ДОМЕН.ru -d www.ВАШ-ДОМЕН.ru
```

Certbot сам добавит SSL в конфиг и настроит автопродление. После этого в
`/opt/karate/server/.env` поменяйте `CLIENT_ORIGIN` на `https://ВАШ-ДОМЕН.ru`
и перезапустите бэкенд: `systemctl restart karate-crm`.

---

## Как обновлять систему (после каждого этапа разработки)

1. Через WinSCP загрузите изменённые файлы в `/opt/karate/server` и `/opt/karate/web`
   (какие именно — я буду писать после каждого этапа).
2. В терминале:

```bash
cd /opt/karate/server && npm install && npm run migrate
cd /opt/karate/web && npm install && npm run build
chown -R www-data:www-data /opt/karate
systemctl restart karate-crm
```

Миграции безопасные (`CREATE TABLE IF NOT EXISTS`) — их можно запускать сколько
угодно раз, данные не пострадают.

## Полезные команды

- Перезапуск бэкенда: `systemctl restart karate-crm`
- Логи бэкенда: `journalctl -u karate-crm -n 100 --no-pager`
- Проверка API: `curl http://localhost:4000/health`
- Консоль базы: `sudo -u postgres psql karate`

## Шаг 10. Автобэкап базы (обязательно!)

Каждую ночь в 3:00 сервер будет сам делать копию базы и хранить её 14 дней.

```bash
mkdir -p /opt/karate/deploy
# файл deploy/backup.sh загрузите через WinSCP в /opt/karate/deploy, затем:
chmod +x /opt/karate/deploy/backup.sh
/opt/karate/deploy/backup.sh          # проверка: должно написать «✓ бэкап создан»
crontab -e                            # откроется редактор; добавьте строку ниже и сохраните
```

Строка для crontab (вставить в конец файла):

```
0 3 * * * /opt/karate/deploy/backup.sh >> /var/log/karate-backup.log 2>&1
```

Копии лежат в `/opt/karate/backups` — раз в месяц скачивайте свежую через
WinSCP к себе на компьютер. Проверить журнал: `cat /var/log/karate-backup.log`.

### Восстановление из копии (если что-то случилось)

```bash
gunzip -k /opt/karate/backups/karate_ДАТА.sql.gz
sudo -u postgres psql -c "DROP DATABASE karate;"
sudo -u postgres psql -c "CREATE DATABASE karate OWNER karate;"
sudo -u postgres psql karate < /opt/karate/backups/karate_ДАТА.sql
systemctl restart karate-crm
```
