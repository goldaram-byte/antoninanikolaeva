# Инструкция владельца — CRM «Школа каратэ Николаевой Антонины»

Это короткий справочник, как пользоваться системой каждый день.
Установка на сервер описана отдельно — в файле `УСТАНОВКА_НА_СЕРВЕР.md`.

## Вход

- Адрес: `https://ВАШ-ДОМЕН.ru/admin` (или `http://IP-сервера/admin`).
- Логин и пароль владельца вы задали при установке (файл `server/.env`).
- С телефона: откройте адрес в браузере → «Установить приложение» /
  «На экран Домой» — админка станет значком, как обычное приложение.

## Первичная настройка (один раз)

1. **Настройки → Филиалы** — переименуйте «Филиал №1…№4», впишите адреса.
   Здесь же филиалы создаются и удаляются.
2. **Настройки → Тренеры** — добавьте тренеров и схему зарплаты каждого:
   «процент от оплат» или «оклад + процент».
3. **Абонементы** — создайте тарифы. У каждого тарифа есть базовая цена и,
   при желании, своя цена для каждого филиала (пустое поле = базовая).
4. **Расписание** — создайте занятия: одно занятие можно сразу поставить
   в несколько дней недели. У занятия есть филиал, тренер, время, вместимость.
5. **Настройки → Бонусы и рефералы** — проценты бонусов (по умолчанию
   пригласившему начисляется 5% баллами с первой покупки друга).

## Ежедневная работа

### Новый человек позвонил / пришёл на пробное
«Воронка продаж» → «Заявка». Двигайте карточку по этапам (Новая → Связались →
Назначена → Пришёл). Внутри карточки — заметки и задачи («позвонить в среду»).
Если человека привёл ученик — впишите его реферальный код (он в карточке
клиента), связь сохранится.

Когда человек решил заниматься — в карточке заявки нажмите **«Сделать
клиентом»**: клиент создастся автоматически, пригласивший и направление
перенесутся сами.

### Записать ученика в группу
Карточка клиента → «Группы (расписание)» → «Изменить» → отметьте занятия.

### Продать абонемент
Карточка клиента → «Абонементы» → «Выдать». Цена подставится по тарифу и
филиалу, минус персональная скидка, можно оплатить баллами. Если ученик
пришёл с середины месяца — поставьте галочку **«Своя цена»** и введите сумму.
Если платит позже — снимите галочку «Оплачен сейчас»: абонемент уйдёт в долг.

### Отметить посещение
«Посещаемость» → выберите дату и филиал → раскройте занятие → галочка «был».
Занятие спишется с абонемента автоматически (безлимит не списывается).
Отмечать могут и тренеры, и администраторы. Если у ученика нет действующего
абонемента — он помечается красным «без абонемента (долг)».

### Записать на персональную тренировку
«Журнал записи» → «Персональные тренировки» → «Записать» (тренер, время,
филиал). Отметка «был» списывает занятие с персонального абонемента.

### Принять оплату долга
«Оплаты и долги» → вкладка «Должники» → откройте клиента → «Принять оплату».
Способы: наличные, перевод, расчётный счёт, онлайн.

### Посмотреть деньги
«Оплаты и долги» → «Операции»: за период, по способам и филиалам, с итогами.
Возврат или удаление операции — кнопки справа в строке.

### Зарплата тренеров
«Зарплата» → выберите месяц. Считается автоматически по схеме каждого
тренера от оплат его учеников. Важно: при выдаче абонемента указывайте
тренера — по этой привязке идёт расчёт.

### Дашборд
Первый экран: цифры по всем филиалам и по каждому отдельно (выбор сверху).

## Сотрудники и права

«Настройки» доступны владельцу. Новых сотрудников можно завести через
запрос к разработчику или API (раздел управления сотрудниками с ролями
можно добавить отдельным доработком). Роли уже заложены: Владелец (всё),
Администратор (всё кроме настроек), Тренер (только свои клиенты,
расписание и отметка посещаемости).

## Бэкапы — ВАЖНО

- Каждую ночь в 3:00 сервер сам делает копию базы в `/opt/karate/backups`
  (хранится 14 дней). Как включить — шаг «Автобэкап» в `УСТАНОВКА_НА_СЕРВЕР.md`.
- Раз в месяц скачивайте свежий файл `karate_*.sql.gz` через WinSCP к себе
  на компьютер — это ваша страховка.
- В панели хостинга включите автосписание оплаты и уведомления о балансе:
  потеря сервера из-за неоплаты — самый частый способ потерять всё.

## Обновления системы

Когда выходит новая версия: загрузите изменённые файлы через WinSCP в
`/opt/karate`, затем в консоли сервера:

```bash
cd /opt/karate/server && npm install && npm run migrate
cd /opt/karate/web && npm install && npm run build
chown -R www-data:www-data /opt/karate
systemctl restart karate-crm
```

Миграции безопасны для данных — их можно запускать сколько угодно раз.
