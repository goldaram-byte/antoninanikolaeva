# Инструкция владельца — CRM «Школа каратэ Николаевой Антонины»

Это короткий справочник, как пользоваться системой каждый день.
Установка на сервер описана отдельно — в файле `УСТАНОВКА_НА_СЕРВЕР.md`.

## Вход

- Адрес: `https://ВАШ-ДОМЕН.ru/admin` (или `http://IP-сервера/admin`).
- Логин и пароль владельца вы задали при установке (файл `server/.env`).
- С телефона: откройте адрес в браузере → «Установить приложение» /
  «На экран Домой» — админка станет значком, как обычное приложение.

## Если совсем не получается войти (запасной путь через консоль)

Обычно сотрудники и пароли меняются в разделе «Настройки → Сотрудники».
Но если войти не получается совсем, помогут команды в консоли сервера —
после каждой выводится список сотрудников.

Создать сотрудника или сменить ему пароль (пароль — от 8 символов):

```bash
cd /opt/karate/server && npm run set-admin -- moya@pochta.ru МойПароль123 "Антонина"
```

Посмотреть, кто есть в системе:

```bash
cd /opt/karate/server && npm run set-admin -- --list
```

Удалить лишнюю учётную запись (последнюю удалить нельзя):

```bash
cd /opt/karate/server && npm run set-admin -- --delete lishniy@pochta.ru
```

**Важно про безопасность.** Сразу после установки удалите учётку
`admin@karate.ru`, которую создаёт первичное наполнение базы, — её пароль
стандартный и известен всем. Пароли делайте длинными и не используйте
примеры из инструкций.

## Первичная настройка (один раз)

1. **Настройки → Филиалы** — переименуйте «Филиал №1…№4», впишите адреса.
   Здесь же филиалы создаются и удаляются.
2. **Настройки → Тренеры** — добавьте тренеров и схему зарплаты каждого:
   «процент от оплат» или «оклад + процент».
3. **Абонементы** — создайте тарифы. У каждого тарифа есть базовая цена и,
   при желании, своя цена для каждого филиала (пустое поле = базовая).
4. **Расписание** — создайте занятия: одно занятие можно сразу поставить
   в несколько дней недели. У занятия есть филиал, тренер, время, вместимость.
5. **Настройки → Бонусы и рефералы** — проценты бонусов (по умолчанию
   пригласившему начисляется 5% баллами с первой покупки друга).

## Перенос существующей базы клиентов

«Клиенты» → кнопка **«Импорт»**. Подойдёт файл Excel (`.xlsx`) или CSV,
первая строка — названия колонок.

После загрузки система показывает **все колонки файла** и рядом с каждой —
сколько значений в ней заполнено («68 из 217» или «колонка пустая»). Для
каждой колонки выбираете, куда её импортировать:

- **Имя / ФИО**, **Телефон**, **Email**, **Дата рождения**, **Пол**,
  **Скидка, %** — в соответствующие поля карточки;
- **Родитель (имя)** и **Телефон родителя** — в блок родителя (по нему в
  карточке сразу есть «Позвонить / WhatsApp / Telegram»);
- **Источник (откуда узнали)**, **Дата добавления клиента** — история клиента
  сохранится как в прежней системе;
- **Ответственный сотрудник** — под списком колонок появится блок «Кто есть
  кто: ответственные из файла»: слева значение из файла (например «admin2»),
  справа — выбор вашего сотрудника. Совпадения по имени подставляются сами,
  остальное выбираете руками;
- **Статус (активный / неактивный)** — «неактивный», «архив», «ушёл»,
  «отказ» распознаются как неактивный, всё остальное — как активный;
- **ID в прежней CRM** — не показывается в карточке, но по нему повторный
  импорт того же файла не создаст дубликатов даже у людей без телефона;
- **Филиал (из этой колонки)** — клиенты разложатся по филиалам прямо из
  файла; галочка «Создавать филиалы, которых ещё нет» добавит недостающие
  филиалы с названиями из файла (адреса потом впишете в Настройках →
  Филиалы). Если колонки с филиалом нет — просто выберите один филиал для
  всех импортируемых;
- **В заметки** и **В заметки (с названием колонки)** — для всего
  остального: пояс, группа, баланс, количество посещений. В карточке это
  выглядит как «Пояс: жёлтый; Посещений: 97». Нули и пустые значения в
  заметки не пишутся.

Внизу списка система сама следит, чтобы ничего не потерялось: если осталась
колонка с данными, которая никуда не идёт, появится жёлтая полоска с её
названием и кнопкой **«Сложить их в заметки»**. Когда всё разобрано —
полоска зелёная: «Все колонки с данными учтены».

Пропуск дубликатов включён по умолчанию: сравниваются телефон (в любом
формате: 8…, +7…, со скобками) и ID из прежней CRM. Поэтому повторный
импорт того же файла безопасен — дубликаты просто пропустятся.

**Если импорт прошёл, но что-то настроено не так** (например, не подставился
ответственный) — не нужно обнулять базу. Включите галочку **«Обновлять уже
заведённых клиентов»** и загрузите тот же файл ещё раз: клиенты не
задвоятся, а их карточки дополнятся. Пустые ячейки в файле ничего не
затирают — то, что вы уже вписали руками, останется на месте. В результате
будет видно, сколько клиентов создано и сколько обновлено.

## Обнулить базу клиентов (например, после пробного импорта)

Если импорт получился неудачным и хочется начать с чистого листа —
в консоли сервера:

```bash
cd /opt/karate/server && npm run reset-clients
```

Эта команда **ничего не удаляет**, а показывает, что есть в базе. Чтобы
действительно удалить:

```bash
cd /opt/karate/server && npm run reset-clients -- --yes
```

Удалятся все клиенты и вся их история: абонементы, оплаты, посещения,
записи, баллы и задачи. Филиалы, тарифы, расписание, тренеры, сотрудники и
настройки останутся. Заявки в воронке продаж тоже останутся — чтобы
очистить и их, добавьте в конец `--leads`.

Перед удалением система сама делает резервную копию базы в
`/opt/karate/backups` (файл `before_reset_…sql.gz`) — из неё всё можно
вернуть, как описано в `УСТАНОВКА_НА_СЕРВЕР.md`.

Лишние филиалы после этого удаляются в Настройках → Филиалы (удалять можно
только пустые — а после обнуления они как раз пустые).

## Выгрузка базы клиентов

«Клиенты» → кнопка **«Экспорт»** — скачается файл Excel с той выборкой,
которая сейчас на экране: учитываются поиск и фильтры по филиалу, тренеру,
ответственному и статусу (чтобы выгрузить всех, поставьте «Все статусы»).
В файле — имя, телефон, статус, филиал, тренеры, направления,
ответственный, дата рождения, пол, родитель и его телефон, email,
источник, скидка, баллы, долг (только тем, кому видны финансы), реферальный
код, дата появления в базе и заметки. Этот же файл можно потом загрузить
обратно через «Импорт» — например, на другой сервер.

Храните выгрузки аккуратно: это персональные данные учеников и родителей.

## Ежедневная работа

### Новый человек позвонил / пришёл на пробное
«Воронка продаж» → «Заявка». Двигайте карточку по этапам (Новая → Связались →
Назначена → Пришёл). Внутри карточки — заметки и задачи («позвонить в среду»).
Если человека привёл ученик — впишите его реферальный код (он в карточке
клиента), связь сохранится.

Когда человек решил заниматься — в карточке заявки нажмите **«Сделать
клиентом»**: клиент создастся автоматически, пригласивший и направление
перенесутся сами.

**Свои этапы воронки.** Кнопка **«Этапы»** справа сверху: добавить новый
этап (например «Пробное занятие»), переименовать любой, выбрать ему цвет,
передвинуть стрелками влево-вправо и удалить ненужный. У каждого этапа есть
тип: «обычный», «успех» — на него заявка встаёт при кнопке «Сделать
клиентом» (такой этап один), и «отказ» — потерянные заявки. Удалить можно
только пустой этап: если на нём есть заявки, система скажет сколько —
сначала перенесите их.

### Что есть в карточке клиента
Контакты ученика и **родителя** (у обоих кнопки «Позвонить / WhatsApp /
Telegram»), филиал, тренеры и направления, **ответственный сотрудник**
(кто ведёт клиента), **статус** (активный / неактивный), дата рождения с
возрастом, пол, источник («откуда узнали»), дата появления в базе, скидка и
баллы, заметки, группы расписания, абонементы, история оплат и посещений.
Поиск в списке клиентов работает и по имени, и по телефону, и по родителю.

**Ответственный сотрудник** выбирается из списка ваших сотрудников (тех, у
кого есть вход в систему, — раздел Настройки → Сотрудники). В списке
клиентов есть колонка «Ответственный» и фильтр по нему — видно, кто чьих
клиентов ведёт.

**Статус.** Активный — занимается; неактивный — перестал ходить, но
историю удалять жалко. Переключается одной кнопкой прямо в карточке
(«Сделать неактивным» / «Вернуть в активные»). Неактивные клиенты не
считаются в цифрах дашборда и не попадают в должники по правилу «записан в
группу, но не оплатил месяц». Список клиентов по умолчанию показывает
активных — в фильтре сверху можно выбрать «Неактивные» или «Все статусы».

### Массовые действия со списком клиентов
Слева в таблице «Клиенты» у каждой строки есть галочка, а в шапке — галочка
«выделить всех в выборке». Отметьте нужных (удобно сначала отфильтровать —
по филиалу, тренеру, ответственному или статусу) — сверху появится панель:

- **Тренер** — выбрать тренера и нажать **+** (прикрепить всех выделенных)
  или **−** (открепить);
- **Направление** — так же прикрепить или убрать направление;
- **Группа расписания** — добавить выделенных в занятие из расписания
  (в списке видно день, время, название и филиал) или убрать из него;
- **Сделать активными / Сделать неактивными** — массовая смена статуса.

Так, например, после импорта базы можно за минуту разложить 200 человек по
тренерам и группам. Повторное прикрепление ничего не задваивает, а перед
откреплением и сменой статуса система переспросит.

### Записать ученика в группу
Карточка клиента → «Группы (расписание)» → «Изменить» → отметьте занятия.

**Тренера к ученику не привязывают вообще.** Тренер группы из расписания и
есть тренер ученика: он виден в карточке («Тренеры (по группам)»), по нему
работают фильтр «Все тренеры» в списке клиентов, режим «только свои» у
тренера-сотрудника и подстановка тренера при выдаче абонемента (от неё
считается зарплата). Поменяли тренера у группы в расписании — он сменился
у всех её учеников сразу.

### Продать абонемент
Карточка клиента → «Абонементы» → «Выдать». Цена подставится по тарифу и
филиалу, минус персональная скидка, можно оплатить баллами. Если ученик
пришёл с середины месяца — поставьте галочку **«Своя цена»** и введите сумму.
Если платит позже — снимите галочку «Оплачен сейчас»: абонемент уйдёт в долг.

### Отметить посещение
«Посещаемость» → выберите дату и филиал → раскройте занятие → галочка «был».
Занятие спишется с абонемента автоматически (безлимит не списывается).
Отмечать могут и тренеры, и администраторы — **любого ребёнка**, даже если
он из другой группы или филиала: кнопка «Добавить» в занятии ищет по всей
базе (по имени, телефону или родителю), режим «только свои клиенты» на
отметку посещений не распространяется. Если у ученика нет действующего
абонемента — он помечается красным «без абонемента (долг)».

**За какую дату можно отмечать.** Тренеры и администраторы отмечают только
за сегодня — задним числом или вперёд система не даст. **Владелец** может
отметить ученика любым числом: и за вчера, и за прошлый месяц. Если нужно
разрешить это кому-то ещё, в Настройки → Сотрудники откройте роль и
поставьте галочку «Отмечать посещаемость за любую дату» — сотруднику
нужно будет перезайти в систему. То же правило действует для персональных
тренировок и для снятия отметок.

Если отметка не ставится, журнал покажет красную полоску с причиной
(например, «Отмечать посещения можно только за сегодня»). Проверьте дату в
поле над списком занятий и роль своей учётной записи: без ограничений
отмечает только роль «Владелец».

### Записать на персональную тренировку
«Журнал записи» → «Персональные тренировки» → «Записать» (тренер, время,
филиал). Отметка «был» списывает занятие с персонального абонемента.

### Принять оплату долга
«Оплаты и долги» → вкладка «Должники» → откройте клиента → «Принять оплату».
Способы: наличные, перевод, расчётный счёт, онлайн.

### Посмотреть деньги
«Оплаты и долги» → «Операции»: за период, по способам и филиалам, с итогами.
Возврат или удаление операции — кнопки справа в строке.

**К какому месяцу относится оплата.** По умолчанию отчёт считает по
**месяцу абонемента**: оплата попадает в тот месяц, с которого действует
абонемент (его «Дата начала» при выдаче), а не в день, когда принесли
деньги. Абонемент за сентябрь, оплаченный 5 октября, показан в сентябре —
в строке видна дата начала и мелко «оплачено 05.10». Так же считаются
«Выручка за месяц» на дашборде и зарплата тренеров. Если нужен кассовый
отчёт — сколько денег реально поступило за период — переключите вверху
«По дате оплаты». Оплаты без абонемента и возвраты всегда идут по дате
самой операции.

Поэтому при выдаче абонемента с середины или за прошлый месяц важно
ставить правильную **«Дату начала»** — именно по ней отчёт раскладывает
деньги по месяцам.

### Зарплата тренеров
«Зарплата» → выберите месяц. Считается автоматически по схеме каждого
тренера от оплат его учеников. Важно: при выдаче абонемента указывайте
тренера — по этой привязке идёт расчёт.

### Дашборд
Первый экран: цифры по всем филиалам и по каждому отдельно (выбор сверху).

## Расписание на сайте школы

Расписание можно показывать на сайте (Tilda или любой другой конструктор) —
оно берётся прямо из CRM и обновляется само.

- **Настройки → Расписание на сайте**: галочка «Показывать расписание на
  сайте», ссылка на страницу расписания и готовый код для вставки с кнопкой
  «скопировать».
- На Tilda: «Добавить блок» → «Другое» → **T123 «HTML-код»** → «Контент» →
  вставить код → «Опубликовать».
- На сайте сразу видны все филиалы (каждый своим блоком с названием и
  адресом), а сверху — кнопки, чтобы посетитель открыл расписание только
  своего филиала. Если на страницу нужен один конкретный филиал — см.
  параметры в `РАСПИСАНИЕ_НА_САЙТЕ.md` (там же тёмная тема и свой цвет).

Посетители сайта видят только день, время, название занятия, филиал, зал и
имя тренера. Ученики, оплаты и посещаемость на сайт не попадают.

## Сотрудники и права

Всё делается в **Настройки → Сотрудники** (раздел виден владельцу).

**Добавить тренера или администратора:** «Добавить» → имя, email (это его
логин), пароль от 8 символов, роль. Пароль передайте сотруднику лично —
в системе он больше не показывается. Кнопка с ключиком в строке
сотрудника меняет ему пароль, если он его забыл.

**Готовые роли:**
- **Владелец** — полный доступ, изменять и удалять нельзя (защита от того,
  чтобы случайно не остаться без входа).
- **Администратор** — всё, кроме настроек школы и управления сотрудниками.
- **Тренер** — в списке клиентов видит только своих, но на тренировке может
  отметить любого ребёнка; расписание, посещаемость (только за сегодня)
  и долги.

**Тренеру — только своих учеников.** У роли «Тренер» стоит режим «только
своих». Чтобы он заработал, в карточке сотрудника выберите, **какому
тренеру** соответствует этот логин (поле появляется само при выборе такой
роли). Тогда в «Клиентах» он увидит только тех, кто закреплён за ним.

**Своя роль под ваши правила:** «Новая роль» → название → «всех клиентов»
или «только своих» → галочки, что разрешено (клиенты, расписание,
посещаемость, абонементы, оплаты, зарплата, настройки и т.д.). Права
применяются сразу — сотруднику даже не нужно перезаходить.

Роль нельзя удалить, пока на ней есть сотрудники — сначала переведите их
на другую.

## Свой пароль

Любой сотрудник может сменить себе пароль сам: кнопка **«Сменить пароль»**
в левом меню внизу, под своим именем. Нужно ввести текущий пароль и новый
(от 8 символов).

## Бэкапы — ВАЖНО

- Каждую ночь в 3:00 сервер сам делает копию базы в `/opt/karate/backups`
  (хранится 14 дней). Как включить — шаг «Автобэкап» в `УСТАНОВКА_НА_СЕРВЕР.md`.
- Раз в месяц скачивайте свежий файл `karate_*.sql.gz` через WinSCP к себе
  на компьютер — это ваша страховка.
- В панели хостинга включите автосписание оплаты и уведомления о балансе:
  потеря сервера из-за неоплаты — самый частый способ потерять всё.

## Обновления системы

Новая версия ставится одной командой в консоли сервера — файлы скачаются
с GitHub сами:

```bash
cd /opt/karate && git pull && cd server && npm install && npm run migrate && cd ../web && npm install && npm run build && chown -R www-data:www-data /opt/karate && systemctl restart karate-crm && echo ОБНОВЛЕНО
```

Если git ругается `detected dubious ownership` — выполните один раз
(это разрешение git работать с папкой, принадлежащей www-data):

```bash
git config --global --add safe.directory /opt/karate
```

Миграции безопасны для данных — их можно запускать сколько угодно раз.
